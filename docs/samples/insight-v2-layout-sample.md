# 观点提炼：AI 翻译为何翻不好“口语”？

> 说明：本文件按「观点提炼 v2」当前内置提示词的固定输出格式，对演示稿人工整理而成，仅用于版式对比，不代表真实模型输出。与 v4 样例（`insight-v4-layout-sample.md`）输入同一篇演示稿。

## 总体概要

视频围绕“为什么 AI 翻译技术很强，翻口语、翻台词却经常翻车”展开。作者是有十五年经验的翻译与本地化从业者，核心立场是：口语翻不好不是“词不认识”，而是“句子的温度丢了”，且通用评测与真实口语使用脱节。关键结论是工程上值得投入的方向不是把模型做得更大，而是把“意图—情境”维度做进评测集与回归集。最大信息增量是团队实测数据：某主流大模型跑 2000 句美剧台词，“直接可用”通过率仅 42%，建成 300 条易错口语回归集后提升到 61%，同期通用 benchmark 只动了 3 分。

## 核心观点与支撑

### 观点1：主流大模型翻美剧口语，“直接可用”的比例只有四成出头

- **现象/背景**：团队今年用某主流大模型跑了 2000 句美剧台词的中译测试，按“能直接使用”的标准打分。
- **作者的判断**：通过率只有 42%，说明大模型翻口语的可用性远低于大众对其“很强”的认知。
- **论据/支撑**：
  - **事实/数据**：2000 句测试中“直接可用”通过率 42%；失败的 58% 里约一半卡在文化梗。
  - **案例/类比**：“take five” 直译是“拿五”，实际是“休息五分钟”；梗词典里查得到，难在判断“该不该翻、该翻成什么”。
  - **逻辑推演**：文化梗难不在词义，而在“该不该翻”是一个隐蔽决策，模型缺少这个判断环节。
- **原文金句/关键表述**：未明确形成一句原话金句；核心表述为“这个‘该不该翻’的判断，其实是个很隐蔽的决策”。
- **边界/局限/反方观点**：未提及

### 观点2：口语翻不好不是“词不认识”，而是“句子的温度丢了”

- **现象/背景**：未明确说明具体背景，作者由日常翻译工作直接引出。
- **作者的判断**：翻译不是在换词，是在换人说话；模型会翻词，但没有“这句话带着什么情绪、说给谁听”的权重。
- **论据/支撑**：
  - **事实/数据**：未明确说明
  - **案例/类比**：“I'm fine, really.” 在强撑时说是“我没事，真没事”，在赌气时说是“我好得很，别管我”，同一句话情境不同意思完全不同。
  - **逻辑推演**：口语语义依赖情境权重，而情境权重是当前模型缺失的维度，因此“温度”丢失。
- **原文金句/关键表述**：翻译不是在换词，是在换人说话。
- **边界/局限/反方观点**：未提及

### 观点3：值得投入的方向不是更大模型，而是把“意图—情境”做进评测集与回归集

- **现象/背景**：通用 benchmark 分数上涨被普遍当作模型进步信号，与口语可用性脱节。
- **作者的判断**：工程上真正值得投入的方向，是把“意图—情境”这类维度做进评测集和回归集。
- **论据/支撑**：
  - **事实/数据**：300 条易错口语例建成回归集；两版模型直接可用率从 42% 提到 61%；同期通用 benchmark 只动了 3 分。
  - **案例/类比**：自家 LQA 流水线的回归集实践。
  - **逻辑推演**：通用分数涨 3 分口语可用性几乎不涨；通用分数不涨口语可用性反而可能大涨，说明两类评测脱节。
- **原文金句/关键表述**：未明确形成一句原话金句。
- **边界/局限/反方观点**：测试以美式英语和影视对白为主，日韩语料还没跑，结论不能外推太远；作者自嘲五年后可能失业，但希望是输给“更好的翻译”而不是“更快的翻译”。

## 论证脉络

作者从“测试结果与大众认知的反差”切入（42% 通过率）→ 用文化梗说明“该不该翻”是隐蔽决策 → 把问题从词义层推进到情境层（温度丢失）→ 给出工程结论（意图—情境进评测与回归集）→ 以边界声明与自嘲收尾。整体是“现象 → 归因 → 主张 → 落地建议”的推进结构。

## 启发与行动

- 做翻译产品评测时，把“情境”做成可回归的测试集，比盯着通用分数更接近真实可用性。
- 翻口语类内容先判断“这句话该不该直译”，再决定翻法。
- 值得继续追问：300 条回归集之外，“该不该翻”的自动判定如何落地。
