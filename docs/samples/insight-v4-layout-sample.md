# 观点提炼：AI 翻译为何翻不好“口语”？

> **一句话读懂**：翻译老兵认为，大模型翻不好口语的根子不在词义，而在“分寸感”缺失、评测错位；与其把模型做得更大，不如把“意图—情境”做进评测集与回归集。
>
> **脉络**：从团队实测“42% 直接可用率”的反差切入 → 用文化梗说明“该不该翻”是隐蔽决策 → 把问题推进到“句子的温度丢了” → 落到“意图—情境进评测与回归集”的工程主张 → 边界声明与自嘲收尾。

---

## 核心观点

**1. 主流大模型翻美剧口语，“直接可用”的比例只有四成出头**

我们团队今年用某主流大模型跑了 2000 句美剧台词的中译测试，按“能直接使用”的标准，通过率只有 42%，与“AI 翻译很强”的大众印象明显脱节。失败样本里约一半卡在文化梗：比如 "take five" 直译是“拿五”，其实是“休息五分钟”——梗本身词典里都有，难的是模型要判断“这里该不该翻、该翻成什么”，而“该不该翻”是一个很隐蔽的决策。

**2. 口语翻不好不是“词不认识”，而是“句子的温度丢了”**

作者把翻译定义为“不是在换词，是在换人说话”，并举例同一句 "I'm fine, really."：强撑时说，是“我没事，真没事”；赌气时说，是“我好得很，别管我”。词义没有变，变的是一句话带着什么情绪、说给谁听——模型恰恰缺少这份“情境权重”，所以翻出来总是少了温度。

> 翻译不是在换词，是在换人说话。

**3. 值得投入的方向不是更大模型，而是把“意图—情境”做进评测集与回归集**

这是作者全片最想落地的建议。他举自家 LQA 流水线的实践：挑 300 条易错口语例建成回归集后，两版模型的直接可用率从 42% 提到 61%，同期通用 benchmark 只涨了 3 分——通用分数与真实口语可用性之间是脱节的，拿通用分数验收翻译能力会掩盖口语层的真实差距。

> 模型翻的是词，人翻的是分寸。

作者也主动划了边界：这套测试以美式英语和影视对白为主，日韩语料还没跑，结论不能外推太远；他自嘲五年后自己可能失业，但希望是输给“更好的翻译”，而不是“更快的翻译”。
