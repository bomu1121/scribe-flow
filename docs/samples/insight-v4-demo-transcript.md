# 演示稿：《AI 翻译为何翻不好口语？》

> 用途：观点提炼 v4 版式评审用的同稿样例输入（模拟口播转写稿，未逐字对应任何真实视频）。
> 作者在稿中的表述均为演示虚构；样例按此稿人工整理，用于对比 v2 / v4 两种输出版式，不代表真实模型输出。

大家好，我做翻译和本地化做了十五年，机器翻译从统计翻译、神经翻译一直看到今天的大模型。今天想聊一个很多人困惑的问题：为什么 AI 翻译技术这么强，翻口语、翻台词还是经常翻车？

先说一个我们自己的数据：我们团队今年用某主流大模型跑了 2000 句美剧台词的中译测试，按"能直接使用"的标准来打分，通过率只有 42%。剩下那 58% 里，差不多有一半卡在文化梗上。你像 "take five" 这种，直译是"拿五"，其实是"休息五分钟"。这种梗不是查不到，词典里都有；难的是它出现的时候，模型得知道这里该不该翻、该翻成什么。这个"该不该翻"的判断，其实是个很隐蔽的决策。

所以我的第二个看法是：口语翻不好，很多时候不是"词不认识"，而是"句子的温度丢了"。我一直跟团队讲，翻译不是在换词，是在换人说话。你听 "I'm fine, really." 这句话，一个人在强撑的时候说，和在赌气的时候说，意思完全不一样，前者可以翻成"我没事，真没事"，后者可以是"我好得很，别管我"。模型会翻词，但它没有这句话带着什么情绪、说给谁听的权重。

第三，我想说工程上真正值得投入的方向，可能不是把模型做得更大，而是把"意图—情境"这种维度做进评测集和回归集里。举我们自己流水线的例子：我们挑出 300 条易错口语例，建成一个回归集，拿两版模型去跑，直接可用率从 42% 提到了 61%；同期那两个模型在通用 benchmark 上的分数只动了 3 分。你看，通用分数涨 3 分，口语可用性几乎不涨；通用分数不涨，口语可用性反而可能大涨——通用评测和真实口语使用之间是脱节的。

我也得承认这套测试的边界：我们以美式英语和影视对白为主，日韩语料还没跑，结论不能外推太远。最后自嘲一句：说不定五年后我就失业了，但我希望自己是输给"更好的翻译"，而不是输给"更快的翻译"。
