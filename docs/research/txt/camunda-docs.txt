## The Camunda 7 Manual

Welcome to the Camunda 7 Manual! Camunda 7 is a light-weight, open-source platform for Business Process
Management. The Manual introduces key concepts in Camunda 7, provides installation procedures as well as a
comprehensive reference section.

## Getting Started

The Guide
Get started with Camunda
is the quickest and easiest way to get up and running with Camunda 7. Alternatives include:

BPMN 2.0

DMN 1.3

Spring Framework
