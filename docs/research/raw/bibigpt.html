What is BibiGPT?

BibiGPT (originally BiliGPT, also known as AI 课代表) is an AI video and audio assistant. Paste any video, audio, podcast or upload a local file and BibiGPT generates a structured, time-stamped summary, full transcript, mind map, and an AI chat surface over the content. Founded by JimmyLv (吕立青) in 2023, served 1M+ users since.

How does BibiGPT summarize videos?

Which platforms does BibiGPT support?

BibiGPT works with YouTube, Bilibili (B 站), TikTok, Douyin (抖音), Kuaishou (快手), Xiaohongshu (小红书), Twitter / X, Vimeo, TED, Coursera, Khan Academy, Apple Podcasts, Spotify, Xiaoyuzhou (小宇宙), Ximalaya (喜马拉雅), and arbitrary web pages with audio or video tags. Local files supported: mp3, mp4, m4a, wav, srt, vtt, ass.

Is BibiGPT free?

Free tier with daily quota (30-min videos). Plus $19.8/mo (year $142.56). Pro $34.8/mo (year $250.56) with vision, batch processing, and API access. Lifetime $888 (limited). Pay-as-you-go credits from $20 (2,000 credits) to $200 (40,000 credits, 50% off per credit).

How do AI agents integrate with BibiGPT?

Four agent surfaces: (1) MCP server at https://bibigpt.co/api/mcp with OAuth 2.0 + Bearer; (2) REST OpenAPI spec at https://bibigpt.co/api/openapi.json; (3) NLWeb /ask endpoint with SSE streaming at https://bibigpt.co/api/ask; (4) Anthropic Skill vianpx skills add JimmyLv/bibigpt-skill. Discovery files: /.well-known/agent-card.json (A2A), /.well-known/mcp.json, /llms.txt, /api/llms.txt, /pricing.md, /index.md. Try /api/discover for a single-call list of all agent entry points, or visit https://bibigpt.co/?mode=agent for a structured JSON view of this homepage.

How does BibiGPT handle privacy?

Uploaded files auto-deleted after 30 days. Summaries default to private and only become public when the user explicitly toggles sharing. BibiGPT does not train on user content without opt-in. Full data export and delete via dashboard. GDPR / CCPA compliant. See the BibiGPT Privacy Policy and security.txt.
