「每次调 API 花了多少」该怎么展示

起因：用户问「每次需要调用 API 的地方有没有 TOKEN / 费用统计」，并要求不许编，要调研出已有项目的成熟设计。 第一轮只做到「记 token + 手填单价算估算」，查证后发现那条路有两个真问题：缓存命中 token 只认了 DeepSeek 的字段名 （其余家一律显示 0，是显示错的数），以及「厂商直接报的金额」被当成估算一起算了。 这一页把六套做法摆在一起对比——前三套是设置页上「单价与对账」那一块，后三套是结果页上「这次花了多少」那一行。 事实与出处见 api-usage-cost-research.md。
