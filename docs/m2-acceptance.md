# M2 验收标准（分层）

> 生效时间：2026-08-28。M2 范围：B 站扫码登录、来源节点快捷选择器（收藏夹/我的合集/稍后再看/B站历史）、本地音视频上传、文本节点校验。
> 验收原则：能自动化的全部自动化；真实登录态与视觉判断用 bsk 真实浏览器；扫码环节必须人工介入。只有所有层级通过，M2 才可标记完成。

|---|---|---|

L4 备注：

## L1 API 自检（不依赖 B 站真实登录）

| # | 请求 | 验收 |
|---|---|---|
| 1 | `POST /api/auth/qr` | 返回 `qrId`、`image`（data URL）、`expiresIn=180` |
| 2 | `GET /api/auth/qr/:qrId`（未扫码） | `status=waiting` |
| 3 | `GET /api/auth/status`（未登录） | `loggedIn=false` |
| 4 | `GET /api/bilibili/fav/folders`（未登录） | 401 + 中文错误「请先登录 B 站」 |
| 5 | `POST /api/files/upload`（合法 mp4） | 返回 `fileId/fileName/storedPath/size`，文件落盘 |
| 6 | `POST /api/files/upload`（txt） | 400 + 中文错误 |
| 7 | `POST /api/auth/logout` | `{ok:true}`，状态回到未登录 |

执行方式：`scripts/m2-api-check.mjs`（Node 原生 fetch，无第三方依赖）。
