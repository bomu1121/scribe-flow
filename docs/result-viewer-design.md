# 运行结果展示页设计方案

> 状态：已按本方案落地到 `apps/web/src/views/RunDetailView.vue` 与 `apps/web/src/components/RunLogDialog.vue`。
> 目标：最终结果不能只输出 Markdown 文件，还要在 Web 上提供可读、可核对、可编辑、可导出的结果页。

## 1. 页面定位

增强现有路由 `/project/:id/run/:runId`，默认展示「结果」Tab，并提供「节点流水」Tab 和日志弹窗：

| Tab | 内容 |
|---|---|
| 结果（默认） | 输入素材 + 输出文档阅读/编辑 |
| 节点流水 | 节点状态、耗时、产物摘要、失败重跑 |
| 日志 | 大尺寸独立日志查看器，支持节点 / 步骤 / 类型 / 关键词筛选、长日志折叠、单条复制与批量下载 |

## 2. 布局

- 顶栏：返回工作流、运行编号、状态、耗时、复制、下载、查看日志。
- 左侧栏（300px，可折叠）：输入素材卡片 + 输出文档列表。
- 主区域：文档工具条 + 白纸文档（max-width 900px，内边距 48–56px）。
- 响应式：<1280px 侧栏收窄，<1024px 编辑分屏变单列，<768px 整体纵向堆叠。

## 3. 多输入 / 多输出

- 输入素材按来源节点编号展示，且可点击切换到该输入单独查看：
  - B 站：封面、标题、UP 主、时长、分 P（元信息在解析/批量选择时写入图数据），并显示该视频独立转写文稿。
  - 本地文件：文件名、大小，并显示该文件独立转写文稿。
  - 文本：前 80 字摘要，点击查看完整文稿。
  - 中间处理节点（转写/AI 加工等）也会作为“链路输入”列出，方便逐段核对。
- 输出文档支持 Tab/列表切换；每个输出独立显示来源溯源、字数、阅读时间。
- 通过运行时图快照（`runs.graph_json`）计算哪些素材汇入当前输出，避免工程后续修改影响历史结果。

### 3.1 多输入分段阅读（2026-09-10 追加）

一个节点消费 N 个输入（如 8 个视频经同一个转写节点）时，引擎产出 N 份独立结果；此前它们被
`combineOutputs` 用分隔线接成一份主输出，阅读时只能一路滚，很难定位到某一个视频。

现在改为「分段阅读」：**默认只显示第 1 段，可切换任意一段，也可切回合并全文**。
分段的形态按容器分层：结果页用右侧「分段大纲」列表（顺序内容不适用标签页），窄屏与画布浮层用
「单行标题 + 下拉」；依据见 [segment-navigation-research.md](./segment-navigation-research.md)。

- 数据来源：`run_node_inputs`（每个输入一行，带 `position` 与独立文本）。转写 / 校对 / AI 加工 / 攻略加工
  取该行的处理结果（`result_text ?? text`）；输出 / 合并 / 条件分支取汇入的每段文本；文本工具这类逐项
  变换的节点取它交付给同一下游节点的多份内容。历史运行无需重跑即可分段。
- 分段标题：沿链路向上走到原始素材，取视频标题（真正的分 P 才补 `· P2 分P名`）、文件名或上游节点名；
  副标题带 UP 主与时长。
- 生效范围（四处共用同一套分段结构与同一个选择器组件）：
  1. 结果页输出文档（拿结果页当笔记读的主区域）：**右侧「分段大纲」栏**（268px、可折叠、段数 > 12 出现筛选框）；
  2. 结果页「链路输入」里点中间节点后的正文：同一个大纲栏；
  3. 画布节点卡片的结果预览浮层：**单行「03 / 08 标题 ▾」+ 展开列表 + ‹ › 翻段**（360px 不铺开 N 个按钮）；
  4. 运行日志弹窗（每条日志标注所属输入，并可按输入筛选）。
- 窄屏（<1280px）自动降级：大纲栏隐藏、工具条下方换成单行标题 + Element Plus 下拉 + ‹ › 翻段；
  移动端沿用该降级形态。
- 顺序阅读：大纲栏底部常驻「‹ 3 / 8 ›」，键盘 `↑ ↓`（或 `j k`）切段、`Home/End` 到首末段，
  焦点跟随选中项；当前项自动滚进大纲可视区（只滚大纲容器，不动整页）。
- 设计依据与控件选型见 [segment-navigation-research.md](./segment-navigation-research.md)：
  标签页/分段控件只适合 2–5（宽界面 ≤7）个并列选项，顺序内容应当用列表导航——
  方案对照稿见 [samples/segment-nav-options.html](./samples/segment-nav-options.html) 与
  [samples/segment-nav-options.png](./samples/segment-nav-options.png)。
- 复制 / 下载 / 目录跟随当前分段：选段后「复制」「下载 Markdown」导出的就是这一段，文件名带段号与段标题。
- 深链：画布浮层在某一段点「查看完整输出」会带上 `?focus=<nodeId>&seg=<index>`；结果页据此打开
  该节点自己的产物（中间节点不再退回到最后一篇输出文档），并定位到同一段。
- 日志归属：新运行写日志时记录 `input_index`/`input_total`；旧运行缺这两个字段时，同一
  （节点 / 类型 / 配方步骤）分组的条数与分段数一致则按写入顺序推断（引擎对同一节点的输入顺序处理）。

## 4. 文档阅读

- 使用 `marked` + `DOMPurify` 渲染 Markdown，禁止未消毒 `v-html`。
- 支持标题、列表、表格、代码块、引用、链接、图片。
- 自动生成目录（TOC），点击跳转。
- 显示字数、预计阅读时间。

## 5. 缩放 / 编辑 / 全屏

- 缩放：75%–200%，通过 CSS 变量控制文档字号，避免 transform 缩放模糊。
- 全屏：Fullscreen API，支持退出。
- 编辑：本地草稿编辑，左右分屏实时预览；支持恢复原始、复制编辑结果；不直接篡改运行记录。

## 6. 返回工作流

- 顶栏「返回工作流」回到 `/project/:id`，并携带 `?focus=nodeId` 在画布中定位并选中对应输出节点。
- 画布内已完成节点会显示「查看输出」按钮，一键跳到该节点在最近一次运行中的结果页，便于调试。

## 6.1 画布调试入口

- 在 `ScribeNode` 上，可能产生文本产物的节点（转写、校对、AI 加工、合并、输出、文本来源）都会在标题栏显示一个紧凑的「查看输出」图标按钮；没有运行记录时会给出提示。
- 运行完成后，节点下方会展示**输出内容摘要**：前 120 字左右的正文预览 + 字数/耗时等元信息，避免只有“xxx 字”的空洞样式。
- 节点底部结果条的徽标可悬停/点击打开「结果预览浮层」，直接查看该节点的中间产物（不再需要跳到详情页）：
  多输入节点在浮层顶部给出分段选择器，默认只渲染第 1 段，可切「全部」。
- 浮层支持一键打开 `/project/:id/run/:runId?focus=nodeId&seg=N` 完整结果页，并停在同一段。
- 结果页会根据 `focus` 参数自动选中对应输出文档；`focus` 指向中间节点时，直接打开该节点自己的产物。

## 7. 实时性

- 运行中打开结果页会通过 SSE 自动刷新；`node.done` / `node.error` / `run.done` 触发节流重载。
- SSE 刷新不会打断当前选择的输入分段。

## 8. 后端配套

- `runs` 表新增 `graph_json`：保存运行时图快照。
- 新增 `GET /api/runs/:id/outputs/:nodeId/content`：读取大文档完整内容（数据库内联文本或文件）。
- `GET /api/runs/:id` 返回 `graph` 字段；旧数据缺失时前端回退到当前工程图。
- `run_node_logs` 新增 `input_index` / `input_total`：日志归属到具体输入（多视频分组与筛选）。
