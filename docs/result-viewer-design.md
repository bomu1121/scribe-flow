# 运行结果展示页设计方案

> 状态：已按本方案落地到 `apps/web/src/views/RunDetailView.vue`。
> 目标：最终结果不能只输出 Markdown 文件，还要在 Web 上提供可读、可核对、可编辑、可导出的结果页。

## 1. 页面定位

增强现有路由 `/project/:id/run/:runId`，默认展示「结果」Tab，并提供「节点流水」Tab 和日志弹窗：

| Tab | 内容 |
|---|---|
| 结果（默认） | 输入素材 + 输出文档阅读/编辑 |
| 节点流水 | 节点状态、耗时、产物摘要、失败重跑 |
| 日志 | 独立弹窗，可按节点过滤 |

## 2. 布局

- 顶栏：返回工作流、运行编号、状态、耗时、复制、下载、查看日志。
- 左侧栏（300px，可折叠）：输入素材卡片 + 输出文档列表。
- 主区域：文档工具条 + 白纸文档（max-width 900px，内边距 48–56px）。
- 响应式：<1280px 侧栏收窄，<1024px 编辑分屏变单列，<768px 整体纵向堆叠。

## 3. 多输入 / 多输出

- 输入素材按来源节点编号展示：
  - B 站：封面、标题、UP 主、时长、分 P（元信息在解析/批量选择时写入图数据）。
  - 本地文件：文件名、大小。
  - 文本：前 80 字摘要。
- 输出文档支持 Tab/列表切换；每个输出独立显示来源溯源、字数、阅读时间。
- 通过运行时图快照（`runs.graph_json`）计算哪些素材汇入当前输出，避免工程后续修改影响历史结果。

## 4. 文档阅读

- 使用 `marked` + `DOMPurify` 渲染 Markdown，禁止未消毒 `v-html`。
- 支持标题、列表、表格、代码块、引用、链接、图片。
- 自动生成目录（TOC），点击跳转。
- 显示字数、预计阅读时间。

## 5. 缩放 / 编辑 / 全屏

- 缩放：75%–200%，通过 CSS 变量控制文档字号，避免 transform 缩放模糊。
- 全屏：Fullscreen API，支持退出。
- 编辑：本地草稿编辑，左右分屏实时预览；支持恢复原始、复制编辑结果；不直接篡改运行记录。

## 6. 返回工作流

- 顶栏「返回工作流」回到 `/project/:id`，并携带 `?focus=nodeId` 在画布中定位并选中对应输出节点。
- 画布内已完成节点会显示「查看输出」按钮，一键跳到该节点在最近一次运行中的结果页，便于调试。

## 6.1 画布调试入口

- 在 `ScribeNode` 上，可能产生文本产物的节点（转写、校对、AI 加工、合并、输出、文本来源）都会在标题栏显示一个紧凑的「查看输出」图标按钮；没有运行记录时会给出提示。
- 运行完成后，节点下方会展示**输出内容摘要**：前 120 字左右的正文预览 + 字数/耗时等元信息，避免只有“xxx 字”的空洞样式。
- 点击后在画布右侧打开「节点输出」抽屉，直接查看该节点的中间产物（不再需要跳到详情页）。
- 抽屉支持复制、下载，并可一键打开 `/project/:id/run/:runId?focus=nodeId` 完整结果页。
- 结果页会根据 `focus` 参数自动选中对应输出文档。

## 7. 实时性

- 运行中打开结果页会通过 SSE 自动刷新；`node.done` / `node.error` / `run.done` 触发节流重载。

## 8. 后端配套

- `runs` 表新增 `graph_json`：保存运行时图快照。
- 新增 `GET /api/runs/:id/outputs/:nodeId/content`：读取大文档完整内容（数据库内联文本或文件）。
- `GET /api/runs/:id` 返回 `graph` 字段；旧数据缺失时前端回退到当前工程图。
